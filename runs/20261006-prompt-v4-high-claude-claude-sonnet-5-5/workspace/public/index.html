Questions

Good to know

Is the constellation really unique?

It's generated from your name, date and sky number, so the same inputs always give the same sky and different inputs give a different one. Every shirt carries a catalogue number derived from its design.

Can I see exactly what will be printed?

Yes. The preview is drawn by the same code that produces the print file. Only the shirt fabric around it is an illustration.

How long does it take?

Each shirt is printed to order after payment clears. Production takes a few days; delivery depends on your country. Tracking is available on your order page once it ships.

Can I return it?

Because every shirt is made for one person, we can't accept returns for sizing or change of mind. If it arrives damaged or misprinted, we'll reprint it. See the returns policy.

Which characters can I use?

Latin letters (including accents like é, ñ, ü), spaces, hyphens and apostrophes in names. Other scripts aren't supported yet.
